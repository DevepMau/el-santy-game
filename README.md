
# El Santy

Juego de gestión y simulación inspirado en un emprendimiento de jardinería y mantenimiento de espacios verdes.

El objetivo es comenzar desde cero, realizar trabajos, mejorar las herramientas y hacer crecer el negocio hasta alcanzar un alto nivel de automatización.

## Objetivo del proyecto

Desarrollar un juego pequeño y escalable que permita explorar mecánicas de trabajo, progresión y gestión de un emprendimiento.

## Características

- Gestión y crecimiento del emprendimiento.
- Trabajos de jardinería y mantenimiento de espacios verdes.
- Mejoras de herramientas y equipamiento.
- Progresión desde el trabajo manual hasta la automatización.
